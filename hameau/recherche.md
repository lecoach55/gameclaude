# Recherche — pistes pour Hameau 3D (8 nov. 2026)

- **Foundation (Polymorph Games)** : city builder sans grille ; les villageois construisent eux-mêmes dans les zones résidentielles peintes ; les chemins naissent des trajets (desire paths). Bâtiments modulaires, maisons évolutives. → déjà notre modèle ; aller vers bâtiments modulaires/annexes.
  Sources : https://www.pcgamesn.com/foundation/roads-desire-paths-city-builders ; https://www.polymorph.games/foundation/news/?p=1384 ; https://www.pcgamer.com/one-of-the-best-city-builders-around-is-getting-a-hefty-update
- **Banished (Shining Rock)** : l'hiver ne produit rien → gros surplus nécessaire ; pêche/chasse s'épuisent si surexploitées ; sols qui s'appauvrissent ; vieillissement et natalité (pyramide des âges) ; citoyens affamés/froids/malades → moins productifs (effet domino). Critique : gestion opaque, catastrophes difficiles à rattraper.
  Sources : https://en.wikipedia.org/wiki/Banished_(video_game) ; https://www.banished-wiki.com/wiki/Banished ; https://www.dedoimedo.com/games/banished.html
- **Manor Lords** : parcelles résidentielles (burgage plots) à contours libres, orientables, avec annexes de jardin (potager, verger, poulailler) ; niveaux de maison selon équipements (puits, marché, église) ; approbation > 50 % pour attirer des familles. Critique de joueurs : dispositions trop « modernes » → préférer orientations variées.
  Sources : https://steamcommunity.com/app/1363080/discussions/0/4355619782840362614 ; https://www.gamespot.com/articles/manor-lords-upgrade-town-village-guide/1100-6523015/ ; https://wiki.hoodedhorse.com/Manor_Lords/Buildings
- **Townscaper (Oskar Stålberg)** : grille irrégulière (triangles fusionnés en quads puis relaxés) → aspect organique ; modèles déformés pour épouser les cases.
  Sources : https://boristhebrave.com/docs/sylves/1/articles/tutorials/townscaper.html ; https://sketchpunklabs.github.io/irregular_grid ; https://mcvuk.com/business-news/when-we-made-townscaper
- **Chaînes et paliers (Anno)** : les habitants montent de palier quand leurs besoins sont couverts ; chaque palier réclame des biens plus élaborés.
  Source : https://www.anno-union.com/en/devblog-residential-tiers/
- **SimCity BuildIt (mobile)** : la simulation communiquait mal ses problèmes → ajout de bulles d'opinion des citoyens.
  Source : https://www.ea.com/amp/news/taking-simcity-to-mobile
- **UX mobile** : tap tolérant aux micro-mouvements, zoom borné et lissé, ne pas submerger le débutant (outils dévoilés progressivement).
  Sources : https://cursa.app/en/page/touch-controls-for-mobile-games-input-patterns-and-feedback ; https://gdevelop.io/blog/mobile-ux-mistakes
