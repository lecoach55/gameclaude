# Sources de modèles 3D joignables depuis le cloud (vérifiées le 19/11/2026, soir)

Le proxy du bac à sable laisse passer `raw.githubusercontent.com`, `api.polyhaven.com` / `dl.polyhaven.org`, `registry.npmjs.org` et PyPI.
**Bloqués** (403 ou refus) : `github.com` (pages et zip), `api.github.com`, `codeload.github.com`, `cdn.jsdelivr.net`,
quaternius.com, kenney.nl, opengameart.org, poly.pizza, sketchfab.com, market.pmnd.rs. Il faut donc connaître le chemin
exact d'un fichier dans un dépôt GitHub (pas de liste de dossier possible).
